# How the pipeline example was made

- Page: `templates/pipeline.html`, built with `node build/build.mjs templates/pipeline.html 178 --out examples/pipeline`.
- Data: none. Stage names, tools and sizes are placeholders (d numbers per item, n poses).
- Picture: PDB 1MEL chain A (single-domain antibody, deposited 1996-06-06), rendered with ChimeraX 1.10 as `vhh__main` in `art/`.
- Colours come from `tokens/tokens.base.json`.
